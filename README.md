#Hexagonal Fruit Number Input Field

###Overview:

This is an interactive gamified input field where users can input their phone number by tapping on falling number-shaped fruits in a fun and colorful way. The game-like experience includes numbers falling in hexagonal shapes and bombs that clear the input if tapped. The game uses the Phaser.js library to handle the falling objects, with a modern Glass-morphism design and candy color gradient background.

###Features:

- Interactive number input using falling number-shaped fruits (0-9).

- Bombs fall with numbers; tapping a bomb clears the input.

- Slower falling speed for more time to tap the numbers.

- Glass-morphism background effect for the game screen.

- Submit button to show the entered phone number in an alert after tapping the numbers.

- Game screen only appears when the input field is activated.

###Installation:

1\. Clone this repository:

git clone https://github.com/tanvir-asif19/Fruit-ninja-number.git

2\. Open the `index.html` file in your browser.

That's it! The gamified input field will work in your browser.

###How It Works:

1\. Number Input:

The main page has an input field where you can input your phone number by tapping on falling fruits with numbers (0-9). The fruits are hexagonal shapes with colorful backgrounds.

2\. Falling Numbers and Bombs:

The numbers fall from the top of the screen in different colors. If you tap on the fruit with a number, it is added to the input field. If you tap on a bomb, the input field is cleared.

3\. Submit Button:

After entering the phone number, you can click the "Submit" button to see an alert with the phone number entered. The game screen will hide after submitting.

4\. Game Pop-up:

The game screen (with the falling fruits) appears as a pop-up when the input field is clicked.

###Technologies Used:

- Phaser.js: A fast, robust, and versatile 2D game framework used for handling the falling objects and interactions.

- HTML/CSS: Used for the design and layout of the webpage.

- JavaScript: Handles the logic of falling numbers, bombs, and user input interactions.
